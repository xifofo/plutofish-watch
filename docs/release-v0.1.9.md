# PlutoFish Watch 0.1.9

- 失败诊断同步到 PlutoFish 发布任务详情：记录发生时间、步骤、HTTP 状态、业务码、115 数字码、请求编号和尝试序号。成功重试后仍可查询、分页和复制历史。
- 上报故障时先保存到本地，重启后补报；历史记录补报不会阻塞原任务恢复，也不会因完成后的清理而丢失。
- 修复历史复用文件失效后反复 HTTP 502：仅在服务端确认候选不存在或不匹配时沿用原任务重新开始上传。普通业务拒绝停止自动重试并显示具体原因；网络、权限、限流与结果未知不会盲目重建。
- 旧服务端未声明诊断能力时保留原上报格式。推荐先升级服务端；旧版没有采集的错误码无法追溯，历史失败任务需要手动重试才能获得新诊断。

已通过 99 项离线测试、类型检查和构建，包括真实本地小视频与模拟 HTTP/OSS 的重启恢复。GitHub Actions 提供 Windows x64、macOS arm64/x64 安装包；未做真实 115 联调，macOS 包未签名、公证。
