# PlutoFish Watch 0.1.12

- 网盘目录支持单击选中，双击或点击右侧箭头进入；保存前显示完整目标路径，创建文件夹也可直接选择上级目录。
- 切换上传账号时清空旧目录选择，忽略迟到的目录响应；加载更多时合并重复目录，避免误选。
- 同步 GVS 发布引擎，改进连接恢复及按季匹配版本；旧任务缺少媒体规格时使用 Watch 配置的本机 ffprobe 补检，检测失败不会开始上传。
- 128 项离线测试、类型检查、构建和实际 Electron 窗口验证通过，覆盖目录选择、窄窗口、深色模式、双路上传、ED2K 和连接恢复。本次待发布源码的密钥扫描通过；未进行真实 115 上传或 Windows 真机安装验收。

安装包由 GitHub Actions 生成，提供 Windows x64 和 macOS arm64/x64 版本。升级时完全退出旧客户端后安装新包，保留原应用数据。
