# PlutoFish Watch 0.1.19

- 上传前的同一次 ffprobe 检测会读出全部音轨与字幕轨（语言、标题、编码、默认与强制标记），资源登记完成后补报给 PlutoFish，小程序据此给版本标注「国语」「粤语」「特效字幕」「双语字幕」「中字」，DIY 专区卡片也优先显示这些信息。
- 补报只是展示信息，失败不影响上传与交付：资源尚未登记或网络错误时按 30 秒到 6 小时退避，最多 5 次；旧服务端不支持时本次跳过。
- 每次启动会为已完成但还没补报的任务（包括升级前上传的）再试一次；没有轨道记录时，只在原文件仍在且内容未改变时重新检测，已清理或改变的文件直接跳过。

需要 PlutoFish 服务端 v0.0.68-beta 及以上提供 `publisher/files/media` 接口；旧服务端照常上传，只是不显示轨道标签。Watch 暂无应用内自动更新，请完全退出旧版后安装，保留原配置、本地文件和发布记录。ffprobe 继续使用电脑上的安装。

已验证离线回归（含真实 ffmpeg 生成的带国配音轨与特效字幕的 MKV）、类型检查和构建；未进行真实 115 联调或 Windows 真机安装验收。发布附件包含 Windows x64、macOS arm64/x64 安装包和 SHA256 校验文件。
