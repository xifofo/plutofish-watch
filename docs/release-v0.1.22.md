# PlutoFish Watch 0.1.22

- 本地文件的保留时长可以按分钟、小时或天设置，范围 30 分钟至 365 天，不再只能按天。监控目录的自动清理和一次性上传都支持。
- 数字和单位分开填写，例如“30 分钟”“2 小时”“1 天”；顶部状态和任务列表按设置的时长显示。

升级后原有设置不变：已设置的天数会自动换算，已经在倒计时的任务到期时间也不变，自动删除仍默认关闭。

需要缩短保留时长时，到“连接与设置 → 监控目录的本地文件”修改。缩短后也会作用于已完成的监控文件，已超过新时长的文件会在下次清理时删除，修改前请确认这些文件不再需要。

更新到此版本后，不能直接装回 0.1.21 及更早版本，旧版无法读取新的设置格式。

已验证离线回归、类型检查、构建和 Windows 实际窗口验收；未进行真实 115 联调或 macOS 真机验收。
