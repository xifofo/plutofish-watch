# PlutoFish Watch 0.1.35

- Windows 默认使用软件渲染，降低常驻窗口对显卡加速路径的依赖。
- 降低空闲监控的磁盘与内存压力：完整补扫改为上一轮完成后等待 30 秒，多个目录串行扫描，重复扫描请求合并。
- 合并文件通知，同一监控两次事件补扫至少间隔 3 秒；扫描过程中收到的通知会保留一次后续补扫。
- 文件、任务及目录错误没有变化时，不再反复写入主记录和备份，也不推送整份任务历史。扫描时间仍在内存更新，下次获取状态时显示。
- 重复启动不会新增后台扫描循环，退出会清理定时器和目录通知。

本版针对空闲监控期间蓝屏报告采取资源与兼容性缓解措施，尚未确认蓝屏根因，不能保证消除内核或驱动异常。文件通知不可用时，发现文件或确认稳定可能额外等待约一轮 30 秒补扫。

可在应用内检查更新，或退出旧版后安装；保留配置、本地文件、发布记录及异常关机恢复能力。安装包和更新清单由 GitHub Actions 自动生成与发布。
