# PlutoFish Watch 0.1.13

- 一次性上传或持续监控整部剧的总目录时，按各文件的名称和 `S1`、`S2`、`Season 02` 等目录识别所属季，同一任务可包含多季。
- 每个文件查询对应季的版本并登记资源，两季相同集号不会串季或误判重复。固定版本用于默认季，其他季按媒体规格自动归类；没有季号线索时使用默认季。
- 升级后，因旧季号不匹配而停在待确认的未发布文件会在补扫时重新识别。已登记文件、已确认版本及人工暂停决定继续保留。
- 文件名与目录季号冲突时可确认季号和集号；队列显示每个文件的实际季集归属。各季仍上传到任务选择的同一网盘目录。
- 135 项离线测试、类型检查、构建和实际 Electron 窗口验收通过，覆盖跨季登记、重启恢复、人工确认及浅色和窄窗口深色布局。未进行真实 115 上传或 Windows 真机安装验收。

安装包由 GitHub Actions 生成，提供 Windows x64 和 macOS arm64/x64 版本。升级时完全退出旧客户端后安装新包，保留原应用数据；Watch 暂无应用内自动更新，ffprobe 仍需在电脑上安装。
