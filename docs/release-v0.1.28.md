# PlutoFish Watch 0.1.28

- 一次性上传全部取消后，批次显示「已取消」和取消数量，不再一直显示「处理中」。部分文件完成、其余取消时显示「已结束」。
- 重新选择文件或目录时，再次核对已取消的旧记录并释放遗留占用，无需重启或先移除原批次。保留取消历史、上传断点和失败诊断，不恢复旧任务，也不按旧批次计划删除文件。
- 如果文件确实仍被其他任务占用，提示会列出具体的监控目录或一次性上传任务名称及本地路径，方便定位。

本版包含 0.1.27 的暂停续传 `PartAlreadyExist` 修复。升级后，失败任务可直接「重试」；已经取消的任务可重新选择原文件新建上传。可在应用内检查更新，或退出旧版后安装，保留配置、本地文件及发布记录。

提供 Windows x64、macOS Apple Silicon 和 Intel 安装包、应用内更新清单和 SHA256 校验文件。验证使用本地临时文件与模拟服务，未进行真实 115 上传或目标设备安装验收。
