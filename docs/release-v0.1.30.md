# PlutoFish Watch 0.1.30

- 自动归类支持全部常见音轨：Opus、Vorbis、LPCM/PCM、ALAC、AC4、WMA、AMR、APE、WavPack、DSD 等不再停在“音轨规格无法确定，请选择版本”，会按实际音轨新建或匹配版本。少见的编码按编码名保留，只有 ffprobe 也认不出编码或声道时才需要选择。
- 文件名里编码和声道连写（`DDP5.1`、`Opus2.0`、`TrueHD7.1`、`DTS-HD.MA5.1`）现在能正确识别，版本名不再多出 `1`、`DDP5`、`HD.MA` 这类碎片标签；之前带着这些碎片建出的版本仍会继续匹配，同一季不会被拆开。DTS-HD MA、DTS:X 和 Atmos 的不同写法保留在音轨上。
- DVD 与电视录制片源：识别 `480i`、`576i`、`1080i` 隔行档位，以及 MPEG2、XviD、VC1 等视频编码；720×480、720×576 的 DVD 画面按 480p、576p 分档，不再误判为 360p。

升级前已经停在“请选择版本”的文件，在“传输任务”中点击“刷新版本”即可重新自动归类。文件名写的音轨与实际不符时（例如写 DDP、实际是 AC3）仍会请你确认。设置、目录和传输记录保持不变。

已验证离线回归、类型检查和构建；未进行真实 115 上传或目标设备安装验收。
