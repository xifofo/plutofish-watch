# PlutoFish Watch 0.1.16

- 修复多个 Watch 或 GVS 共用发布 Key 时互相打断秒传校验的问题：没有本机匹配成品的待办静默跳过，不替其他客户端回报不可用。
- 刚发布时本机完成状态尚未同步，稍后继续校验；保留同绑定同内容成品提供摘要的能力。
- 同步 GVS 发布引擎修复。配套服务端保留原 30 秒校验窗口，单台客户端的不可用或清理回报不会终止其他客户端的机会。

请先升级 PlutoFish 服务端，再更新全部 GVS、Watch 客户端。完全退出旧版后安装，保留原配置、本地文件与发布记录；已失败的转存需明确重试。Watch 暂无应用内自动更新，ffprobe 仍使用电脑上的安装。

验证：154 项离线测试、类型检查、发布引擎快照校验和构建通过。Windows x64、macOS arm64/x64 安装包由 GitHub Actions 生成；未进行真实 115 联调或真机安装验收。
