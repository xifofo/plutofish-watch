# PlutoFish Watch 0.1.17

- 同步 GVS 发布引擎的持续校验流水线，最多同时处理 16 个读取或回执任务，慢回执不再堵住后续待办。
- 同一成品的指纹恢复合并执行；回执失败可以重新扫描，旧响应不会跳过重试任务。
- 关闭时等待进行中的校验收尾，继续保留共用发布 Key 的客户端隔离行为。

建议先升级配套 PlutoFish 服务端，再完全退出旧版并安装。保留原配置、本地文件和发布记录。Watch 暂无应用内自动更新，ffprobe 仍使用电脑上的安装。

验证使用离线测试、类型检查、发布引擎快照校验和构建；未进行真实 115 联调或 Windows 真机安装验收。发布附件包含 Windows x64、macOS arm64/x64 安装包和 SHA256 校验文件。
