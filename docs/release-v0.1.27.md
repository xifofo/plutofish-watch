# PlutoFish Watch 0.1.27

- 修复暂停后继续上传或重试一直提示 `HTTP 409 PartAlreadyExist` 的问题。远端已经接收、但本地尚未保存回执的分片，现在会与原文件的大小和 MD5 核对，一致后继续原任务。
- 续传时如果远端稍晚才确认已有分片，会补查当前分片后继续；大小或摘要不一致时保留断点并显示具体原因。
- 保留原上传会话、已确认分片、作品版本和任务记录，避免为恢复暂停任务重复上传整文件。

可在应用内检查更新，或退出旧版后安装新包。保留原配置、本地文件及发布记录。升级后对原失败任务点击「重试」，暂停中的任务点击「继续」即可，无需取消任务或重新选择文件。

提供 Windows x64、macOS Apple Silicon 和 Intel 安装包，以及应用内更新清单和 SHA256 校验文件。离线回归与构建不代表真实 115 上传或目标设备安装验收。
