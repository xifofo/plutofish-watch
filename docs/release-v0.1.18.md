# PlutoFish Watch 0.1.18

- 同步 GVS 发布引擎的 Range 调度优化，当前页按空闲槽连续处理，减少固定等待和重复领取，最多仍有 16 个读取或回执任务在途。
- 正常成功摘要不再重复刷新任务、同步重写整份监控清单；本地文件恢复后仍会清除原不可用提示。
- 服务端通知暂不可用时，有任务后一秒补领，连续空闲逐步退避到 15 秒；保留失败重放、断线恢复、关闭收尾和共享 Key 的客户端隔离。

沿用现有 Range 接口，本次优化不要求新增服务端接口。Watch 暂无应用内自动更新，请完全退出旧版后安装，保留原配置、本地文件和发布记录。ffprobe 继续使用电脑上的安装。

已验证离线回归、类型检查、发布引擎快照一致性和构建；未进行真实 115 联调或 Windows 真机安装验收。发布附件包含 Windows x64、macOS arm64/x64 安装包和 SHA256 校验文件。
