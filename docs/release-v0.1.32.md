# PlutoFish Watch 0.1.32

- 自动归类时，如果文件名与实际媒体规格不符，提示会逐项写明哪一项不符：视频编码、HDR、音轨、声道或帧率，并同时列出文件名的写法和实测值。例如 `音轨：文件名写 DDP，实测 AC3`。
- 文件内没有音轨、文件名却标了音轨时，会直接提示 `实测没有音轨，请检查文件`。这种成品通常是重新封装时丢了音轨，仍不会自动发布；带上音轨重新封装并替换原文件后，会自动重新识别。

本版只调整提示内容，判定规则不变，不改变界面、上传和清理流程。可在应用内检查更新，或退出旧版后安装，保留配置、本地文件及发布记录。

已验证离线回归、类型检查和构建；未进行真实 115 上传或目标设备安装验收。
