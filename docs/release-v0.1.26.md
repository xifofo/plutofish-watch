# PlutoFish Watch 0.1.26

- 修复取消一次性上传后，重新选择同一文件仍提示「与现有任务重叠」的问题。取消文件现在会释放路径，可以直接另建任务，原取消历史保留。
- 同一批次中其他未取消文件继续原任务；全部取消后，可以重新选择原目录或文件。
- 旧批次不再重新扫描已取消文件，并停止本批自动删除，避免影响重新添加的任务。取消前已发出的请求即使稍后成功，也不会恢复旧批次的删除计划。
- 升级前已取消的一次性任务在启动时自动释放路径，无需逐条移除历史记录。

可在应用内检查更新，或退出旧版后安装新包。保留原配置、本地文件及发布记录。升级后重新选择此前取消的文件即可；仍在处理或保留中的其他文件继续执行重叠检查。

提供 Windows x64、macOS Apple Silicon 和 Intel 安装包，以及应用内更新清单和 SHA256 校验文件。离线测试及构建不代表真实 115 联调或目标设备安装验收。
