# PlutoFish Watch 0.1.15

- 修复“同一版本已有该集或电影的其他内容”在本地反复拦截上传的问题。同版本同集的不同内容交给服务端按首个成功登记的正片去重，电影冲突继续遵守服务端回执。
- 旧版本产生的本地冲突失败任务，以及依赖失败任务而被错误跳过的副本，会在监控和上传启用后自动重新检查，无需删除任务或重建监控目录。
- 同内容副本等待原任务的发布结果，原任务失败后可继续，不阻塞其他集。已有上传记录的重试保留原任务键、版本和断点。
- 保留人工暂停、取消、文件变更及服务端拒绝的处理边界，不将查重失败当作资源不存在。

验证：153 项离线测试、类型检查、发布引擎快照校验和构建通过。安装包包含 Windows x64、macOS arm64/x64 及 SHA256 校验和；未进行真实 115 上传或真机安装验收。

升级时完全退出旧客户端后安装新包，保留原应用数据。连接后保持目录监控和上传开启，旧本地冲突任务会自动重新检查；人工暂停的任务仍需手动继续。Watch 暂无应用内自动更新，ffprobe 仍需在电脑上安装。
