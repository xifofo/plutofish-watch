# PlutoFish Watch 0.1.11

- 一次性上传新增「选择文件」，支持单选或多选同一目录内的视频，可在提交前移除已选文件；保留原有目录上传入口。
- 文件模式按第一个所选文件识别作品，仅上传本次选中的视频。清单持久化，重启和后续新增文件不会扩大上传范围。
- 同目录中互不重叠的一次性文件任务可分别创建；与已有任务文件、持续监控或整目录清理范围重叠时明确提示。
- 文件模式的自动清理默认关闭。开启后仅删除所选视频，保留父目录、未选视频及附属文件；所选文件改变或正在用于本地校验时停止或暂缓清理。
- 126 项离线测试、类型检查、构建及实际 Electron 窗口验证通过，覆盖多选、取消选择、移除文件、上传与 ED2K 同步、清理范围、窄窗口和深色模式。未进行真实 115 上传或 Windows 真机安装验收。

安装包由 GitHub Actions 生成，提供 Windows x64 和 macOS arm64/x64 版本。升级时完全退出旧客户端后安装新包，保留原应用数据。
