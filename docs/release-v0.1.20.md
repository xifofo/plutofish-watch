# PlutoFish Watch 0.1.20

- 新增应用内更新：启动后和之后每 6 小时检查一次 GitHub 最新正式发布，发现新版本时弹窗显示版本、发布日期、安装包大小和更新内容，可选择“立即更新”或“暂不更新”。
- 立即更新会下载本机对应的安装包并显示进度，可随时取消；大小和 SHA256 与发布清单一致才安装。Windows 自动退出、安装并重新打开；macOS 打开安装包，把新版拖入“应用程序”替换旧版。
- 暂不更新后本次运行不再弹出，可从侧栏“新版本”、托盘菜单或“连接与设置 → 版本更新”重新打开；下次启动或发布了更新的版本时再次提示。
- 正在传输的文件会先保存进度再退出，重新打开后从断点继续；设置、目录和传输记录保持不变。

本版本需要手动安装一次：完全退出旧版后安装，保留原配置、本地文件和发布记录。之后的版本可在应用内更新。更新检查与下载直接访问 GitHub，网络受限时可在弹窗点击“在浏览器中下载”。ffprobe 继续使用电脑上的安装。

已验证离线回归、真实窗口更新验收、类型检查和构建，并在 Windows 本机用测试安装包完成从旧版到新版的下载、校验、安装和重新打开；macOS 更新流程尚未在真机验证，未进行真实 115 联调。发布附件包含 Windows x64、macOS arm64/x64 安装包、SHA256 校验文件和应用内更新清单 latest.json。
