# PlutoFish Watch 0.1.29

- 修复一次性上传完成后，重新选择同一文件仍提示「与现有任务重叠」的问题。任务已完成且没有待执行的自动删除时，不再占用本地路径，可以直接新建上传，无需先移除旧任务。原任务和历史记录保留。
- 开启了自动删除的任务在删除完成前继续占用路径，避免文件在重新上传期间被清理；点击「取消删除」后即可重新选择。仍在处理中的任务和持续监控目录继续执行重叠检查。

本版只调整路径占用规则，不改变上传和清理流程。相同内容传到同一版本时，沿用已有结果。可在应用内检查更新，或退出旧版后安装，保留配置、本地文件及发布记录。

提供 Windows x64、macOS Apple Silicon 和 Intel 安装包、应用内更新清单和 SHA256 校验文件。验证使用本地临时文件与模拟服务，未进行真实 115 上传或目标设备安装验收。
