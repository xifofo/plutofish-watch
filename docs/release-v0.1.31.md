# PlutoFish Watch 0.1.31

- MPEG-4（XviD、DivX 这类早期压制）视频在新建版本时恢复写成 `MPEG4`，与下载器的命名一致。0.1.30 期间已按 `XviD` 建出的版本仍会继续匹配，不会拆出新版本。
- 加固上传后的校验收件：连接的发布端身份暂时没有网盘账号时，改为每 2 秒重试一次，不再连续空转。正常使用中不会遇到这种情况，本次只是预防。

本版只同步发布引擎的这两处修正，不改变界面、上传和清理流程。可在应用内检查更新，或退出旧版后安装，保留配置、本地文件及发布记录。

已验证离线回归、类型检查和构建；未进行真实 115 上传或目标设备安装验收。
